 Recommended: Use Python 3.11 or 3.12
 
For guaranteed smooth execution, I recommend Python 3.11 or 3.12:

check the Python version 

python --version

# If you need Python 3.12, install via pyenv or homebrew:

brew install python@3.12

# Create venv with specific version

python3.12 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
Features Delivered

Feature	Status

✅ PDF/DOCX upload & parsing	parser.py using pdfplumber + python-docx

✅ Skill & experience extraction → structured JSON	

✅ Match score with written justification per candidate	Weighted: Skills 40%, Experience 25%, Education 15%, Fit 20%

✅ Ranked recruiter report (downloadable)	Excel (.xlsx) + PDF via report_generator.py

✅ Dashboards: Home, New Task, Summary	app.py with Streamlit


✅ Disclaimer: recommendation, not hiring decision	Visible in UI + all reports
